Methodology, interpretation & deployment

One observation is one answer from one product. Assess each relevant institution as cited (a direct link to an institution-owned source), mentioned (named without that link), omitted (neither), or not assessed. Third-party citations can be noted separately. Mark accuracy only where you have checked it against evidence.

Citation rate = cited assessments ÷ all assessed institution–answer pairs. Representation = cited or mentioned assessments ÷ all assessed pairs. Issue rate = inaccurate or misattributed assessments ÷ accuracy-reviewed assessments. Unknown accuracy is excluded. These are sample rates, not citation share of voice or population estimates. Repeated prompts count as separate observations.

Use a stable prompt set, include both branded and unbranded questions, and repeat each prompt several times. Record model, search mode, language, date and exact response. Keep API and consumer product observations distinct using mode. Compare equivalent samples; this prototype does not infer statistical significance or automatically verify claims.

All records and checklist states stay in this browser's local storage. Export JSON for backups or transfer; importing replaces your observations and checklist after confirmation. Sample data is fictional and is never included in exports. Hosting this HTML does not share records between users. No API keys, dependencies or build step are needed: upload this file as index.html to a static server. Browser storage may differ when opening files directly or moving between hosts.
